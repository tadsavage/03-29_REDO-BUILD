The 6-Chunk Core Gameplay Loop Plan

This is the complete pallet/case lifecycle: Vendor PO → Inbound → Putaway → Replenishment → Order Selection → Shipping → Invoicing.

CHUNK 1: INBOUND PROCESS ✅ Built (2026-07-03, not yet compile-verified)
What it does: Truck arrives with PO, gets scanned/received, pallets get Load IDs and inventory records
Built:
WorkQueueSystem — task queue (Pending/Assigned/Complete)
LoadIDGenerator — unique 10-digit load IDs per pallet
ReceivingService — processes shipment → creates Putaway tasks
Wired into TruckController: when unload timer expires, dock → receives pallets → queues Putaway tasks
CHUNK 2: OFFLOAD / DOCK-STOCKER ✅ Built (2026-07-03, not yet compile-verified)
What it does: Manned dock stocker (Forklift operator) unloads all 12 pallets from docked trailer → stages them in Inbound lanes with Load IDs
Built:
TrailerOffloadController — scripted choreography (drive, align, lift, drop, register pallet)
New truck lifecycle: docked truck waits AwaitingOffload until offload finishes (or 45s timeout fallback)
Pallet visuals (ChepStack prefab), ghost material while docked
Two manual Inspector assignments still needed:
Assign ChepStack.prefab → TruckController.palletVisualPrefab
Assign trailer mesh + decals → TruckController._ghostWhileDockedRenderers
CHUNK 3: PUTAWAY PROCESS — Next to build
What it does: Reach Truck Operator pulls Putaway tasks from queue → drives pallet jack → determines Pick vs Reserve slot based on order demand → drops pallet, updates location
Key logic: Pick slot for fast-moving SKUs, Reserve for slower ones
CHUNK 4: ORDER SELECTION PROCESS
What it does: Customer order arrives → empty outbound trailer backed to dock → Order Selector hand-picks cases from inventory into staging lane
Includes: Hand animation (Tad's domain), max 2 pallets per selector
CHUNK 5: SHIPPING PROCESS
What it does: Loader moves staged pallets into outbound trailer → trailer departs
Result: Order marked "Shipped"
CHUNK 6: INVOICING PROCESS
What it does: Customer charged (COGS + $1/case handling) → revenue credited to FinanceCategory
Result: Order marked "Invoiced"
